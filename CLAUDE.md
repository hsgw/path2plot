# Instructions for Claude

## Communication

- Always respond in Japanese, concisely.
- Never open a response with filler phrases like "Great question!" or "もちろん!". Start with the answer in the first sentence.
- This file (CLAUDE.md) must always be written in English.

## Workflow

- If you need to edit a file that is not already part of the current context, ask the user for permission first.
- Before and after working on any page implementation, check `reference/implementation-status.md` and update the relevant page's status/notes to reflect current progress.

## Git

- Do not run `git commit` unless the user explicitly instructs you to commit.
- Write commit messages in Japanese, kept to a single short line.
- Run `npm run format` before committing.
